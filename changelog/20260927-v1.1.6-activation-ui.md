# 1.1.6-activation (Week 1 Activation UI)

## Setup
- Folder-first Setup wizard with four visible steps (Site Google app → Connect → Pick folder/Doc → First sync).
- Primary CTA **Watch a client folder** with agency subcopy; secondary **Link one Google Doc instead**.
- Done state **You're set** with links to Sources, Sync Activity, and Drive Folders.
- OAuth callback failures redirect back to Setup with mapped error codes, retry/reconnect/copy affordances, and no REST error hang.
- Credential save success copy: **Site Google app saved.**

## Operations
- Cron-health banner on Setup, Sources, Drive Folders, and Sync Activity (reuse workspace heartbeat; flag `DISABLE_WP_CRON` without ticks).
- Empty-state copy aligned for Sources, Drive Folders, and Sync Activity; Sources empty state offers folder + one-Doc CTAs.
- Sync Activity rows emphasize Doc title, target post, status, time, **View post**, and **Retry** on errors.
- HTML ZIP import continues when individual images fail; sync completes with a partial-success message and failed image count.
- Post editor meta box one-line one-way sync help.

## Deviations from brief
- Existing 1.1.x already shipped folder-first CTAs and cron banner on Sources/Drive Folders; this release extends copy, four-step rail, OAuth redirect UX, logs banner, and partial image success (previously a failed image aborted the whole ZIP import).
