Significance: minor
Type: added

A two-column table at the top of a Google Doc can now set the post title, slug, excerpt, featured image, categories, tags, author, and Yoast SEO or Rank Math title and description. The table is removed from the synced content. It is on for new installs and off for upgraded sites until enabled under Sync defaults. A Categories or Tags row replaces the post's terms, so sync names any WordPress terms it removes in the sync message; delete that row from the Doc to leave WordPress terms alone.
